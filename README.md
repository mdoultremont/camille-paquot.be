# Camille Paquot

Responsive reproduction of [camille-paquot.framer.website](https://camille-paquot.framer.website/) using TanStack Start, React, TypeScript and Tailwind CSS. Images and Castoro/Lexend fonts are served locally.

## Local development

Use Node.js 22.12 or newer.

```sh
npm ci
npm run dev
```

Open http://localhost:3000.

```sh
npm run typecheck
npm run build
npm run preview
```

`preview` serves the production build through the local Cloudflare Workers runtime. The Cloudflare Vite plugin produces `dist/client` and `dist/server`.

## Cloudflare Workers

The project is configured for Cloudflare Workers with the native Cloudflare Vite plugin and the TanStack Start server entry. No deployment has been performed.

When ready to publish:

```sh
npx wrangler login
npm run deploy
```

Set an account or custom domain in `wrangler.jsonc` when connecting your Cloudflare account. `npm run cf-typegen` regenerates the Worker environment types when bindings change. No secrets or database are required.

Setup follows the official [Cloudflare TanStack Start guide](https://developers.cloudflare.com/workers/framework-guides/web-apps/tanstack-start/) and [TanStack build guide](https://tanstack.com/start/latest/docs/framework/react/build-from-scratch).

## Content and routes

Shared components live in `src/components`, French copy in `src/content.ts`, styles in `src/styles.css` and route files in `src/routes`. `src/routeTree.gen.ts` is generated by TanStack.

The reference website's current labels, spelling and URLs are preserved, including these unusual route mappings:

| Route                                          | Content                         |
| ---------------------------------------------- | ------------------------------- |
| `/`                                            | Accueil                         |
| `/a-propos`                                    | À propos                        |
| `/accompagnement`                              | Accompagnement thérapeutique    |
| `/formation-continue`                          | Formation continue              |
| `/accompagnement/therapie-individuelle-enfant` | Thérapie enfant - adolescent    |
| `/accompagnement/therapie-individuelle-ado`    | Thérapie inviduelle pour adulte |
| `/accompagnement/therapie-individuelle-adulte` | Soutien à la parentalité        |
| `/accompagnement/soutien-parentalite`          | Cours de Yoga                   |

Formation continue has no footer in the source. The Wednesday cabinet location appears in the mobile footer, matching the reference. Booking links lead to Rosa, and contact links use telephone and email handlers. The mobile menu and email-copy control are implemented in React. The site has no contact form.

The `sharp` override selects the patched transitive version used by the Cloudflare development tooling.

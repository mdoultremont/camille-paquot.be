# Camille Paquot

This website introduces Camille Paquot, a psychologist offering therapeutic support for children, adolescents, adults and families. It also presents her yoga classes and continuing education.

The planned website address is [camille-paquot.be](https://camille-paquot.be).

The site is built with TanStack Start, React, TypeScript and Tailwind CSS, and is configured for Cloudflare Workers hosting. It has not yet been deployed.

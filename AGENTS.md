# AGENTS.md

## Language

- Write code, comments, commit messages, branch names and PR titles/bodies in English, even when the conversation is in French.
- Website copy shown to visitors stays in French.

## Pull requests

- Write PR bodies with the `pr` skill.

## Workflow

- Use pnpm only, never npm or yarn.
- Before opening a PR, run what CI runs: `pnpm lint`, `pnpm format:check`, `pnpm typecheck`, `pnpm build`.
- Do not edit `src/routeTree.gen.ts` by hand; it is generated by the TanStack router plugin.
